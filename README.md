# screener

시장 상황판과 레버리지 ETF·개별주 스크리너. 하루 한 번 미국 장 마감 16분 뒤(뉴욕 16:16 · 한국 아침 6시 16분, 서머타임 5시 16분) 확정 종가로 계산한다.

- **상황** 탭 — 시장 전반: 주가(SPY · QQQ · SOXX의 최고가 대비 단계 · 200일 평균) · 분위기(불안 VIX · 부도 걱정 · 월봉 과열) · 진입 신호(옐로우닷)
- **종목** 탭 — 종목마다 옐로우닷 · 최소 시드(옐로우업다운 9종목 · 스위치법) · 주의 · 급락 위험
- 맨 위 **장중** 버튼 — 지수와 모든 종목을 지금 가격으로 다시 센다(장중은 Finnhub 무료 키, 프리장은 키 없이 Webull 공개 시세 · 막히면 서버가 받아 둔 `pre.json`이나 Alpaca 무료 키). 임시 값이라 저장하지 않는다

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 (상황 탭 · 종목 탭). 아래 JSON들을 읽기만 한다 |
| `etfs.json` | 종목 탭의 레버리지 ETF 목록 — 이름·기초자산·설명 등. **ETF 추가·수정은 여기 한 곳** |
| `tickers.txt` | 직접 추가한 종목 (한 줄에 하나 · `#` 뒤 메모가 목록 줄 설명 · 메모가 'ETF'로 시작하면 1배 ETF) |
| `market.py` | 가격 받기 · 지표(%K·RSI · 월봉 과열 꺾임에는 CCI도) · 옐로우닷 · 회복 여부 · 옐로우업다운 — 아래 두 파일이 같이 쓴다 |
| `prices.py` | 종가 수집 → `data.json` (종목 탭) |
| `desk.py` | 상황판 계산 → `desk.json` (VIX 선물 · 하이일드 스프레드 · 회사채 스프레드도 받는다) |
| `pre.py` | 프리장 시세 → `pre.json` (켠 날만 10분마다 · 종목 번호는 `wbid.json`) |
| `fund.json` | 개별주 재무 (손으로 넣는다) |
| `desk_log.json` | 2026-11-23까지의 옛 상황판 판정 기록 — 더 쓰지 않는다 |
| `tests.py` | 계산 시험 (`python3 tests.py`, 인터넷 없이 돈다) |

## 자동 실행

- 제시간 수집은 Claude 예약 작업(뉴욕 월~금 16:16)이 맡는다. 아직 안 받았으면(`prices.py --check`) 아래 워크플로를 수동 실행으로 시작시킨다.
- `.github/workflows/prices.yml` — `prices.py` → `desk.py` 순서로 돌고 결과를 커밋한다. `desk.py`가 실패해도 종가는 저장된다.
  GitHub 예약 실행은 몇 시간씩 늦거나 빠질 수 있어 예비로만 둔다(한국 화~토 07:23 · 10:47 · 14:17, 이미 다 받았으면 건너뜀).
  야후가 장 마감 뒤 몇 시간 동안 그날 일봉을 안 올려 두면 시세 요약으로 마지막 하루를 채운다(`market._fill_last`).
- `.github/workflows/pre.yml` — 프리장 시세. 예약 없이 필요한 날만 켠다(화면 안내 칸 '서버에서 받기 시작' 또는 Run workflow).
- `.github/workflows/test.yml` — 계산 코드나 종목 목록이 바뀌면 `tests.py`를 돌린다.

자세한 규칙과 근거는 `CLAUDE.md`에 있다.
